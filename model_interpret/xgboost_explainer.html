01 · The unit

What a leaf node actually is

Every tree ends in leaves. A leaf is not the prediction — it's a single number, in volume units, that gets added to the running total. A row answers the yes/no questions down the tree, lands in exactly one leaf, and collects that leaf's value.

Below is one tree on its own (trained at full strength so the leaves are easy to read). The baseline is the training mean; each leaf is a deviation from it. Land in the far-right leaf and you add +527,687; land in the far-left and you add −913,999.

02 · The rule

Trees don't vote. They add.

This is the one idea that makes gradient boosting click. The trees are not averaged and they don't take a majority vote. Each tree predicts the leftover error of all the trees before it, and every leaf it produces is summed into the total:

prediction = 2,362,030 (the average)
  + tree  0 → +10,100
  + tree  1 →  +5,933
  + tree  2 → +10,975
  + tree  3 →  −2,334 ← pulls back down
       ⋮    (200 trees)
  = 2,519,557 ← final prediction

Two things make each tree deliberately weak: they're shallow (max_depth 4) and every leaf is shrunk by the learning rate (0.05) before being added. So no single tree matters much — the model improves in hundreds of careful little steps. That's exactly what keeps it from overfitting.
